# Школьный помощник

Анимированная веб-презентация исследовательской работы о Telegram-боте [@school_qwen_helper_26_bot](https://t.me/school_qwen_helper_26_bot).

**Смотреть:** https://benji-hue.github.io/school-helper-presentation/

Управление: → / пробел / клик — дальше, ← или правый клик — назад, F — полный экран.

Работает и без интернета: скачайте репозиторий (Code → Download ZIP) и откройте `index.html` в Chrome или Edge.

Шрифт Manrope распространяется по лицензии SIL Open Font License, текст лицензии в `fonts/OFL.txt`.
